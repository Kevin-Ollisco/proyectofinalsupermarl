## 🚀 Instalación y uso

1. Clona el repositorio
   ```bash
   git clone https://github.com/Kevin-Ollisco/proyectofinalsupermarl.git
   ```
2. Entra a la carpeta del proyecto
   ```bash
   cd proyectofinalsupermarl
   ```
3. Instala las dependencias
   ```bash
   npm install
   ```
4. Ejecuta el proyecto
   ```bash
   node main.js
